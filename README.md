# Grand Prix 3D

A 3D F1-style racing game that runs in the browser (three.js, no build step).

## Deploy on Render
1. Push these files to a GitHub repository (index.html must be in the root).
2. On Render: New > Static Site > connect the repository.
3. Build command: leave empty. Publish directory: .
4. Click Create Static Site.

## Controls
- Left / Right or A / D: steer
- Down or S: brake (brake + steer to drift)
- Space or Shift: nitro
